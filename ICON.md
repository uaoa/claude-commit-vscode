# Icon

`icon.png` (512×512) is the Commit Pen mark: a geometric 10-ray asterisk with rounded ends in sky blue (#38BDF8) next to a cream Git branch graph with three commit nodes, on a dark charcoal rounded square.

Rules for future changes:
- Do not go back to the orange (Claude-colored) asterisk or reuse another extension's icon — the Marketplace locked this listing in 2026-10 for duplicating `juanlb.claude-commit`, and rejected the restyled orange asterisk as "still the same".
- Keep the Git element and the dark tile so the icon stays distinct from other commit-message extensions.
- Stay within the Marketplace limit (max 1024×1024, PNG). 512×512 is the target.
- The Source Control button uses VS Code's built-in `$(sparkle)` codicon; that is a standard icon and is fine to keep.
