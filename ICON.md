# Icon

`icon.png` (512×512) is the Commit Pen mark: a light Git branch graph with two commit nodes and a branch ending in a yellow four-point sparkle (plus a small one), on an indigo rounded square.

Rules for future changes:
- No asterisk in any color or style, and no Claude / Anthropic logo. The Marketplace locked this listing in 2026-10 and rejected both a restyled orange asterisk and a blue one ("the logo is still being used").
- Do not reuse another extension's icon.
- Stay within the Marketplace limit (max 1024×1024, PNG). 512×512 is the target.
- The Source Control button uses VS Code's built-in `$(sparkle)` codicon; that is a standard icon and is fine to keep.
