# Icon

`icon.png` (512×512) is the Claude Git Commit mark: a geometric 10-ray asterisk with rounded ends (a nod to Claude, redrawn from scratch) next to a cream Git branch graph with three commit nodes, on a dark charcoal rounded square.

Rules for future changes:
- Do not use the original Claude / Anthropic logo file or another extension's icon unchanged — the Marketplace locked this listing in 2026-10 for duplicating `juanlb.claude-commit` (same orange asterisk).
- Keep the Git element and the dark tile so the icon stays distinct from other "Claude commit" extensions.
- Stay within the Marketplace limit (max 1024×1024, PNG). 512×512 is the target.
- The Source Control button uses VS Code's built-in `$(sparkle)` codicon; that is a standard icon and is fine to keep.
